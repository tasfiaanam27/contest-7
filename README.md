# TypeScript Problem Solving – Part 2

This repository contains solutions to 10 TypeScript problem-solving challenges, ranging from easy to medium difficulty. 

## Problems Solved

1. **Countdown Time Formatter** – Converts a given number of seconds into a formatted `HH:MM:SS` string.
2. **Notification Badge Counter** – Processes notification events to update the unread notification count.
3. **Nested Folder File Counter** – Uses recursion to count files within nested folder structures.
4. **Student Ranking with Ties** – Sorts students by score and assigns competition ranks while handling ties.
5. **Best Discount Selector** – Identifies the eligible discount offer that produces the lowest payable price.
6. **Elevator Floor Tracker** – Simulates elevator movements while maintaining minimum and maximum floor boundaries.
7. **Find Free Time Intervals** – Determines available time slots by processing overlapping and out-of-range bookings.
8. **Max Non-Overlapping Tasks** – Uses a greedy algorithm to maximize the number of non-overlapping scheduled tasks.
9. **Reconcile Product Inventory** – Updates inventory quantities based on stock-in and stock-out transactions.
10. **Connected Friends** – Uses breadth-first search (BFS) to count people in a connected friendship network.

## Concepts Practiced

- TypeScript Functions, Interfaces, and Type Annotations
- Arrays, Objects, Maps, and Sets
- Loops and Conditional Statements
- Recursion and Nested Data Structures
- Array Methods (`map`, `sort`, `filter`)
- Sorting and Competition Ranking
- Greedy Algorithms and Task Scheduling
- Interval Processing and Overlap Handling
- Graph Representation and Breadth-First Search (BFS)
- Simulation and State Management
- Edge Case Handling and Time Complexity Analysis
